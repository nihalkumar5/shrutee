# Happy Birthday Shrutee ✨ (2nd August 2026)

A modern, magical, interactive birthday web application created for **Shrutee** with glowing starlight aesthetics, 60fps canvas fireworks, audio synthesizer, candle blowing interaction, surprise box generator, and secret letter unboxing.

## Features ✨
- **Zero-Config Vercel Ready**: Works out of the box on Vercel with static web serving.
- **2nd August 2026 Birthday Countdown**: Live countdown timer for Shrutee's birthday.
- **Interactive Surprise Box**: Tap "🎁 Get A Birthday Surprise!" for fireworks showers, musical tunes, secret compliments, and virtual crown ceremony!
- **Web Audio Synthesizer**: Plays a soothing "Happy Birthday" chime melody with play/pause/mute toggle.
- **Interactive Candle Blow**: Tap candle flames to blow them out and trigger a fireworks confetti explosion!
- **Secret Letter Envelope**: Wax-sealed envelope that unfolds with typewriter text animation.
- **Starlight Memory Wall**: Polaroid frames with custom birthday illustrations.

## Deployment on Vercel 🚀

### Method 1: Automatic GitHub Integration (Recommended)
1. Push this repository to GitHub: `https://github.com/nihalkumar5/shrutee.git`.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository **`nihalkumar5/shrutee`**.
4. Click **Deploy**. Vercel will automatically host it in seconds with HTTPS!

### Method 2: Vercel CLI
```bash
npx vercel
```
